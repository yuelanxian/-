# 06 · 电脑使用（桌面客户端、WebDAV、rclone）

本文介绍在 Windows、macOS、Linux 电脑上使用 HomeVault 的几种方式：Nextcloud 桌面客户端（支持"虚拟文件"，2 TB 的归档也不会占满电脑硬盘）、系统自带的 WebDAV 连接，以及 rclone。IP 模式下，电脑必须先安装 HomeVault 根证书，这一步放在最前面讲。

相关文档：[docs/01-架构与安全.md](01-架构与安全.md) · [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) · [docs/05-安卓手机备份.md](05-安卓手机备份.md) · [docs/07-备份与恢复.md](07-备份与恢复.md) · [docs/09-常见问题.md](09-常见问题.md)

> 下文用 `HV_HOST` 代表你的访问地址中的主机部分，例如 `192.168.1.10` 或 `cloud.example.com`。HTTPS 端口不是 443 时，所有地址都要带上端口，例如 `https://192.168.1.10:4443/…`。

## 1. 准备：让电脑连得上、信得过服务器

### 1.1 网络

- **在家：** 电脑连着家里网络，直接访问 `https://HV_HOST`。
- **在外（笔记本）：** 先连 WireGuard VPN，见 [§1.3](#13-笔记本外出用-wireguard-vpn)。

### 1.2 安装根证书（IP 模式必须）

访问地址是 IP（例如 `https://192.168.1.10`）时，服务器证书由 HomeVault 自己的本地证书机构签发，电脑必须先信任它。

**为什么必须装进"系统"证书库：** HomeVault 服务器会发送 HSTS（强制安全传输）头。Nextcloud 桌面客户端遇到 HSTS 时，不再提供"总是信任该证书"的选项，只会报错：

> 服务器强制执行严格的传输安全，不接受不受信任的证书。

所以根证书必须装进操作系统的受信任根证书库，而不是在客户端里点"信任"。

**第 1 步：拿到证书文件和指纹。** 管理员在服务器上运行：

```bash
sudo ./hv ca --export /tmp/HomeVault-CA.crt      # Linux 服务器
```

```powershell
.\windows\hv.ps1 ca                              # Windows 服务器（会显示导出的文件位置）
```

命令会显示证书文件的位置（文件名以命令显示的为准，下文以 `HomeVault-CA.crt` 为例）和 **SHA-256 指纹**，请记下来。把 `.crt` 文件复制到要安装的电脑上（U 盘、局域网共享都可以；根证书本身不是机密，但安装前必须核对指纹）。

> 如果要在 HomeVault 服务器（Windows）本机上使用浏览器或客户端，同样按下面的 Windows 方法，把 `ca` 命令导出的文件装进本机即可。

**第 2 步：按系统安装。**

**Windows 10/11**（管理员 PowerShell）：

```powershell
# 先核对指纹：输出应与服务器上 ca 命令显示的完全一致
$c = [Security.Cryptography.X509Certificates.X509Certificate2]::new("$HOME\Downloads\HomeVault-CA.crt")
[BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash($c.RawData)).Replace('-', ':')

# 一致后，安装到"本地计算机 → 受信任的根证书颁发机构"
certutil -addstore -f ROOT "$HOME\Downloads\HomeVault-CA.crt"
```

也可以用图形界面：双击 `.crt` 文件 → **安装证书** → 存储位置选"**本地计算机**" → "**将所有的证书都放入下列存储**" → 浏览 → "**受信任的根证书颁发机构**" → 完成。

**macOS**（终端）：

```bash
# 核对指纹
openssl x509 -noout -fingerprint -sha256 -in ~/Downloads/HomeVault-CA.crt
# 安装到"系统"钥匙串并设为信任
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/HomeVault-CA.crt
```

也可以用"钥匙串访问"：把文件拖到左侧的"**系统**"钥匙串 → 双击证书 → 展开"信任" → "使用此证书时"选"**始终信任**"。

**Linux（Debian / Ubuntu）**：

```bash
openssl x509 -noout -fingerprint -sha256 -in HomeVault-CA.crt   # 核对指纹
sudo cp HomeVault-CA.crt /usr/local/share/ca-certificates/homevault.crt   # 文件名必须以 .crt 结尾
sudo update-ca-certificates
```

其他发行版请参考它们的文档中"添加受信任 CA"一节。

**浏览器的特殊情况：** Windows 和 macOS 上的 Chrome、Edge 使用系统证书库，装好后重启浏览器即可。**Firefox** 默认使用自己的证书库：设置 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入 → 勾选"信任由此证书颁发机构来标识网站"。Linux 上的 Chrome/Chromium 也可能需要在浏览器设置里单独导入。

⚠️ **安全提醒：** 信任了这个根证书的电脑，会相信它签发的**任何**网站证书，所以根私钥非常重要（它保存在服务器的 Caddy 数据里，也包含在加密备份中，详见 [docs/01-架构与安全.md](01-架构与安全.md) §3.6）。只在自家电脑上安装；电脑卖掉或送人之前，把它从证书库里删除。有域名时建议改用域名模式，就完全不用装证书了。

### 1.3 笔记本外出：用 WireGuard VPN

**第 1 步：为这台电脑生成一个单独的配置**（每台设备一个，不要和手机共用）：

- **Linux 服务器：** 在 wg-easy 网页（`https://HV_HOST:8443`）点"新建客户端"，输入 `laptop-baba` → 点下载按钮，得到 `.conf` 文件。启用二步验证之前，也可以运行 `sudo ./hv vpn add laptop-baba`，配置保存在 `clients/laptop-baba.conf`。
- **Windows 服务器：** 管理员 PowerShell 运行 `.\windows\hv.ps1 vpn add laptop-baba`。配置保存在 `clients\laptop-baba.conf`。程序询问是否删除这个文件时，先选"否"，把文件安全地复制到笔记本上之后再手动删除。

⚠️ `.conf` 文件里有这台电脑的 VPN 私钥：不要放进网盘、不要发到聊天工具，导入后删除服务器上和传输途中的副本。

**第 2 步：安装 WireGuard 客户端并导入：**

| 系统 | 安装 | 导入 |
|---|---|---|
| Windows | 官方安装程序 <https://download.wireguard.com/windows-client/wireguard-installer.exe> | 打开 WireGuard → "从文件导入隧道" → 选 `.conf` → "连接" |
| macOS | Mac App Store 里的 WireGuard；如果你所在地区的商店里找不到，可以用 Homebrew 安装 `wireguard-tools`，用命令行 `wg-quick` 连接 | App：导入 `.conf` 后连接；命令行：`sudo wg-quick up ./laptop-baba.conf` |
| Linux | `sudo apt install wireguard-tools` | `sudo install -m 600 laptop-baba.conf /etc/wireguard/homevault.conf && sudo wg-quick up homevault`；或者用 NetworkManager：`nmcli connection import type wireguard file laptop-baba.conf` |

**使用要点：**

- **在家时断开 VPN。** 在家用 VPN 需要路由器支持"NAT 回流"，很多路由器不支持，结果反而连不上（见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §6）。
- WireGuard for Windows 只在**连接时**解析一次 DDNS 域名。家里公网 IP 变了以后连不上，就"断开"再"连接"一次。
- 配置是分流的：只有去 HomeVault 的流量走隧道，其他上网不受影响。

## 2. Nextcloud 桌面客户端（推荐）

### 2.1 下载和安装

当前稳定版 **34.0.4**（2026-09-16 发布，截至 2026-09）。35.0.0 还在候选版（RC）阶段，请用稳定版。

| 系统 | 安装文件 | 系统要求 |
|---|---|---|
| Windows | `Nextcloud-34.0.4-x64.msi` | Windows 10 及以上，64 位 |
| macOS | `Nextcloud-34.0.4.pkg` | macOS 12 及以上 |
| Linux | `Nextcloud-34.0.4-x86_64.AppImage` | 64 位；需要 GNOME Keyring 或 KWallet 来保存登录凭据 |

下载地址：<https://github.com/nextcloud-releases/desktop/releases>（每个文件旁边还有 `.asc` 签名文件），或 Nextcloud 官网的安装页面 <https://nextcloud.com/install/>。

- **Linux AppImage：** 下载后 `chmod +x Nextcloud-34.0.4-x86_64.AppImage`，然后双击或在终端运行它。
- **管理员批量部署 Windows 客户端**（可选）：`msiexec /passive /i Nextcloud-34.0.4-x64.msi SKIPAUTOUPDATE="1"`。`SKIPAUTOUPDATE="1"` 会关闭客户端的自动更新，之后需要你自己定期升级；家庭使用一般不需要加这个参数。

### 2.2 登录

1. IP 模式下，先完成 [§1.2](#12-安装根证书ip-模式必须) 的根证书安装。
2. 打开客户端 → "**登录**" → "**服务器地址**"填访问地址，例如 `https://192.168.1.10`（和手机上填的完全一样）。
3. 客户端会"**打开浏览器**"，在网页里登录、输入二步验证码，然后点"**授权访问**"。
4. 客户端自动获得一个属于这台电脑的**应用密码**，你的登录密码不会保存在电脑上。以后可以在网页的 个人设置 → 安全 → **设备和活动链接** 里看到并撤销它。
5. 接着选择**本地同步文件夹**和同步方式，见下一节。

登录时报"服务器强制执行严格的传输安全，不接受不受信任的证书。"，说明根证书没有装进系统证书库，回到 [§1.2](#12-安装根证书ip-模式必须)。

### 2.3 虚拟文件：2 TB 的归档也不会占满电脑硬盘

"虚拟文件"让服务器上的所有文件都**显示**在电脑上，但只有你打开某个文件时才真正下载，平时几乎不占空间。

**Windows（基于系统的"云文件"功能，和 OneDrive 的体验类似）：**

- 添加账号时勾选"**使用虚拟文件而非立即下载内容**"；已经添加的账号，可以在客户端设置里，点同步文件夹旁边的"⋮"→"**启用虚拟文件支持…**"。
- 在资源管理器里右键文件或文件夹：
  - "**始终在本地可用**"：下载下来，离线也能打开；
  - "**释放本地空间**"：删除本地副本，只保留占位，服务器上的文件不受影响。
- 要求：本地同步文件夹必须在 **NTFS** 分区上；**不能**是分区根目录（请用 `D:\Nextcloud` 这样的子文件夹，而不是 `D:\`）；**不能**是网络驱动器。

**macOS（File Provider）：**

- 新添加的账号默认就使用 File Provider：文件出现在"访达"侧边栏的 Nextcloud 位置里，打开时才下载。
- Nextcloud 官方建议服务器配合 `notify_push`（Client Push）使用 File Provider。HomeVault 默认没有部署它，所以在别的设备上做的修改，要等客户端定期检查时才会出现，会有一点延迟，不影响使用。

**Linux：** 没有 Windows 那样的虚拟文件，请用下一节的**选择性同步**。

### 2.4 选择性同步：给 2 TB 归档的建议

在客户端设置里点"**选择同步内容**"，逐个文件夹决定是否同步到这台电脑：

| 服务器上的文件夹 | 建议 | 原因 |
|---|---|---|
| `/文档`、正在处理的工作资料 | **完整同步** | 经常用，离线也要能打开 |
| `/手机备份` | **不同步**，或只用虚拟文件 | 数据量大，而且是手机的备份。⚠️ 在电脑上删除或移动这里的文件，会同时删除或移动服务器上的备份 |
| 大型照片 / 影视归档（包括额外存储） | **不同步**，或只用虚拟文件 | 需要时在网页上下载，或用 rclone 按需获取 |

另外两个建议在设置里保持打开：

- "**请求确认同步，在新文件夹大于 … MB 时**"：别人（或手机）新建了很大的文件夹时，先问你要不要同步；
- "**在同步外部存储之前要求确认**"：额外存储（多块硬盘）通常很大，先确认再同步。

⚠️ **同步是双向的。** 在同步文件夹里删除文件，服务器上的文件也会被删除（进入回收站）。误删后，在网页"文件"左下角的"**回收站**"里恢复；回收站的保留期有限，超过保留期的文件只能从服务器备份里找回（见 [docs/07-备份与恢复.md](07-备份与恢复.md)）。

⚠️ 不要在 HomeVault **服务器本机**上用桌面客户端同步 Nextcloud，更不要把同步文件夹设在 Nextcloud 数据目录或额外存储所在的目录里，否则文件会"自己同步自己"，造成混乱。

### 2.5 第一次导入大量旧资料

桌面客户端适合日常同步，不适合一次性导入几十万个文件或几百 GB 的数据。导入旧资料有更好的办法：

| 办法 | 速度 | 说明 |
|---|---|---|
| **把硬盘接到服务器上，作为"额外存储"** | 最快（不经过网络） | 资料原地不动，直接出现在 Nextcloud 里，见 [docs/02-Linux部署.md](02-Linux部署.md) §7 或 [docs/03-Windows部署.md](03-Windows部署.md) §6 |
| **rclone copy** | 快，可断点续传 | 通过网络上传到 Nextcloud，见 [§4.3](#43-常用命令) |
| 复制进桌面客户端的同步文件夹 | 最慢 | 小批量时可以这样做 |

## 3. WebDAV：不装客户端直接访问

### 3.1 地址和应用密码

**WebDAV 地址：**

```text
https://HV_HOST/remote.php/dav/files/用户名/
```

- 例如 `https://192.168.1.10/remote.php/dav/files/mama/`；
- "用户名"是**登录名**（例如 `mama`），不是显示名（例如"妈妈"）；
- 也可以在网页版"文件"左下角的"**文件设置**"里找到"WebDAV URL"，直接复制。

**必须使用应用密码：** HomeVault 强制二步验证，并且禁止第三方程序用登录密码登录（`token_auth_enforced`）。所以 WebDAV、rclone 等程序只能用**应用密码**：

1. 网页右上角头像 → **个人设置** → **安全**；
2. 在页面底部"**应用的名称**"里填用途，例如 `rclone-办公电脑`；
3. 点"**创建新应用密码**"，复制显示的密码。它**只显示这一次**，请立即填到程序里或存进密码管理器；
4. 每个程序、每台电脑各建一个。某台电脑不用了或丢了，在"设备和活动链接"里单独撤销即可。

### 3.2 Windows：映射网络驱动器（能用，但不推荐）

```powershell
# 用 * 代替密码，系统会提示你输入（避免密码留在命令历史里）
net use Z: https://192.168.1.10/remote.php/dav/files/mama/ /user:mama *
```

需要知道的限制：

- 依赖 Windows 的 **WebClient** 服务。这个服务默认不启动，微软已在 2023 年 11 月宣布弃用它。没有运行时，`net use` 会报"**系统错误 67**"。可以这样启动：

  ```powershell
  sc.exe config WebClient start= auto
  net start WebClient
  ```

- **单个文件大小有上限**，由注册表 `HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters\FileSizeLimitInBytes` 控制，默认只有约 50 MB。超过时报错 `0x800700DF`。最大可以改到 `4294967295`（4 GB）：

  ```powershell
  reg add HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters /v FileSizeLimitInBytes /t REG_DWORD /d 4294967295 /f
  net stop WebClient
  net start WebClient
  ```

- 驱动器显示的可用空间是 C 盘的，不是服务器的；
- IP 模式下，根证书必须装在"**本地计算机** → 受信任的根证书颁发机构"（[§1.2](#12-安装根证书ip-模式必须) 的方法就是装在这里）。

因为这些限制，Windows 上更推荐用桌面客户端、rclone 或 RaiDrive。

### 3.3 macOS：访达

访达 → 菜单栏"**前往**" → "**连接服务器…**"（⌘K）→ 输入 `https://HV_HOST/remote.php/dav/files/用户名/` → 用户名 + **应用密码**。

### 3.4 Linux：文件管理器

- **GNOME 文件（Nautilus）：** 左侧"**其他位置**" → 底部"**连接到服务器**"输入 `davs://HV_HOST/remote.php/dav/files/用户名/`，用户名 + 应用密码。
- **KDE Dolphin：** 地址栏输入 `webdavs://HV_HOST/remote.php/dav/files/用户名/`。

## 4. rclone：导入、同步、挂载都能做

rclone 是开源的命令行工具，支持 Windows、macOS、Linux，对 Nextcloud 有专门的适配（分块上传大文件等）。从官网 <https://rclone.org/downloads/> 下载。

### 4.1 创建连接

运行 `rclone config`，按提示操作：

1. `n` 新建，名字填 `homevault`；
2. 存储类型（Storage）选 **webdav**；
3. `url` 填 `https://HV_HOST/remote.php/dav/files/用户名/`；
4. `vendor` 选 **nextcloud**；
5. `user` 填登录名，`pass` 选择自己输入，填**应用密码**；
6. 其余保持默认，保存。

生成的配置大致如下：

```ini
[homevault]
type = webdav
url = https://192.168.1.10/remote.php/dav/files/mama/
vendor = nextcloud
user = mama
pass = （rclone 处理过的应用密码）
```

⚠️ 配置文件里的 `pass` 只是经过"混淆"，**不是加密**，拿到这个文件的人可以还原出应用密码。请保护好这个文件（可以在 `rclone config` 里给配置文件设置密码）；不再使用时，到网页上撤销这个应用密码。

**IP 模式：** 在每条命令后面加上 `--ca-cert <根证书路径>`，让 rclone 信任 HomeVault 的证书。下面的例子都带了这个参数；域名模式可以去掉。

### 4.2 先测试一下

```bash
rclone lsd homevault: --ca-cert ~/HomeVault-CA.crt        # 列出网盘根目录下的文件夹
```

### 4.3 常用命令

```bash
# 把本地文件夹上传（复制）到 Nextcloud，显示进度；中断后重新执行会跳过已完成的文件
rclone copy "/home/mama/老照片" "homevault:照片归档/老照片" --progress --ca-cert ~/HomeVault-CA.crt

# 检查两边是否一致（只比较，不修改）
rclone check "/home/mama/老照片" "homevault:照片归档/老照片" --ca-cert ~/HomeVault-CA.crt

# 从 Nextcloud 下载一个文件夹到本地
rclone copy "homevault:手机备份/小米14-妈妈/相机/2026" "/home/mama/下载/2026照片" --progress --ca-cert ~/HomeVault-CA.crt
```

Windows 上路径写成 `"D:\老照片"`，证书路径写成 `--ca-cert C:\HomeVault\HomeVault-CA.crt`。

- ⚠️ **导入和备份请用 `copy`，慎用 `sync`。** `sync` 会让目标"变得和来源一模一样"，也就是会**删除**目标里多出来的文件。方向写反了，后果很严重。
- 大文件自动分块上传，默认块大小 10 MiB，可以用 `--webdav-nextcloud-chunk-size` 调整。
- 通过 rclone 上传的文件会立即出现在 Nextcloud 里，不需要管理员扫描。

### 4.4 挂载成盘符或文件夹

**Windows**（先安装 WinFsp：<https://winfsp.dev/>）：

```powershell
rclone mount homevault: X: --network-mode --vfs-cache-mode writes --ca-cert C:\HomeVault\HomeVault-CA.crt
```

- 挂载后，"此电脑"里会出现 X 盘，可以像普通网络驱动器一样浏览；
- 这个命令窗口要一直开着，按 `Ctrl+C` 取消挂载；
- 没有 WebClient 服务的 50 MB 文件大小限制。

**Linux**（需要 FUSE，Debian/Ubuntu 上安装 `fuse3`）：

```bash
mkdir -p ~/HomeVault
rclone mount homevault: ~/HomeVault --vfs-cache-mode writes --ca-cert ~/HomeVault-CA.crt
```

### 4.5 图形界面的替代品：RaiDrive（Windows）

RaiDrive 是一款把网盘映射成盘符的 Windows 软件，基础功能免费，高级功能收费。它有专门的 Nextcloud 连接类型：地址填 `HV_HOST`，账号填用户名和**应用密码**。IP 模式下，同样需要先按 [§1.2](#12-安装根证书ip-模式必须) 把根证书装进 Windows。

## 5. 访问额外存储（多块硬盘）

管理员通过 `storage.conf` 添加的额外存储（例如"照片归档""影视资料"），在 Nextcloud 里显示为**根目录下的文件夹**，名字就是 `storage.conf` 第一列的"名称"。

- **谁能看到：** `storage.conf` 最后一列为空时所有用户可见，否则只有列出的用户或群组（`@群组名`）可见。
- **只读存储（`ro`）：** 可以浏览、下载，不能上传、修改或删除，适合存放不希望被误删的资料。
- **在桌面客户端里：** 同步前会先询问（"在同步外部存储之前要求确认"）。大型存储建议用虚拟文件或选择性同步，不要整个下载到电脑上。
- **用 WebDAV / rclone：** 地址和普通文件一样，例如 `homevault:照片归档/2019`。
- **直接往服务器硬盘里放的文件：** HomeVault 把额外存储设置成"每次访问时检查变化"，打开对应文件夹时通常就能看到新文件。如果看不到，请管理员运行：

  ```bash
  sudo ./hv occ files:scan --all              # Linux
  ```

  ```powershell
  .\windows\hv.ps1 occ files:scan --all       # Windows
  ```

  文件很多时，扫描可能需要较长时间。
- **是否包含在服务器备份里：** 只有 `storage.conf` 里"是否备份"为 `yes` 的存储才会被 restic 备份，见 [docs/07-备份与恢复.md](07-备份与恢复.md)。

添加、删除额外存储的方法见 [docs/02-Linux部署.md](02-Linux部署.md) §7、[docs/03-Windows部署.md](03-Windows部署.md) §6 和 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §6。

## 6. 常见问题

| 现象 | 原因 | 办法 |
|---|---|---|
| 客户端提示"服务器强制执行严格的传输安全，不接受不受信任的证书。" | IP 模式下根证书没装进系统证书库 | [§1.2](#12-安装根证书ip-模式必须) |
| 浏览器能打开，客户端或 rclone 报证书错误 | 证书只装在了浏览器（例如 Firefox）自己的证书库；rclone 没加 `--ca-cert` | 按 [§1.2](#12-安装根证书ip-模式必须) 装进系统证书库；rclone 加上 `--ca-cert` |
| 在家正常，出门连不上 | 没连 VPN，或 VPN 没握手 | [§1.3](#13-笔记本外出用-wireguard-vpn)；排错见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §10 |
| 出门正常，回家连不上 | 在家还开着 VPN，路由器不支持 NAT 回流 | 在家断开 VPN |
| WebDAV、rclone 提示用户名或密码错误 | 用了登录密码；应用密码被撤销；用户名写成了显示名 | 创建并使用应用密码（[§3.1](#31-地址和应用密码)），用户名填登录名 |
| Windows 映射驱动器报"系统错误 67" | WebClient 服务没运行 | [§3.2](#32-windows映射网络驱动器能用但不推荐) |
| Windows 映射驱动器复制大文件报 `0x800700DF` | 超过了 WebClient 的文件大小上限 | 修改 `FileSizeLimitInBytes`，或改用 rclone / 桌面客户端 |
| Windows 上无法启用虚拟文件 | 同步文件夹在分区根目录、非 NTFS 分区或网络驱动器上 | 换到 NTFS 分区上的子文件夹，例如 `D:\Nextcloud` |
| 误删了文件 | 同步是双向的 | 网页"文件"左下角的"回收站"里恢复；超过保留期的见 [docs/07-备份与恢复.md](07-备份与恢复.md) |
| 客户端突然要求重新登录 | 这台电脑的授权在"设备和活动链接"里被撤销了，或密码被重置 | 重新登录 |

更多问题见 [docs/09-常见问题.md](09-常见问题.md)。
