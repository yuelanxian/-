# 05 · 安卓手机自动备份（最重要的一篇）

目标：家里每一部安卓手机拍的照片和视频、截图、微信保存的图片、下载的文件，**在家和在外都能自动备份**到 HomeVault，而且手机上的原件一张不少。

整个过程每部手机大约 30 分钟，只需要做一次。请按顺序完成，每一步做完再进行下一步。

相关文档：[docs/04-VPN与DDNS.md](04-VPN与DDNS.md)（VPN 原理与排错） · [docs/06-电脑使用.md](06-电脑使用.md) · [docs/07-备份与恢复.md](07-备份与恢复.md) · [docs/08-日常运维与升级.md](08-日常运维与升级.md)（手机丢了怎么办） · [docs/09-常见问题.md](09-常见问题.md)

## 0. 开始之前

### 0.1 你将会得到什么

```text
手机：相机 / 截图 / 微信图片 / 下载 / 文档
  │  Nextcloud App「自动上传」，在后台自动进行
  │  （在家：通过家里 Wi-Fi 直接连接；在外：通过 VPN 隧道连回家）
  ▼
https://HV_HOST —— HomeVault 上的 Nextcloud，存到 /手机备份/<设备名>/…
  │  服务器每晚用 restic 加密备份
  ▼
另一块硬盘 / 异地对象存储
```

- **Nextcloud App** 负责把照片和文件上传到 `/手机备份/<设备名>/…`；
- **WG Tunnel**（或 WireGuard 官方 App）负责在外面时自动连回家，在家时自动断开；
- **DAVx⁵**（可选）负责同步通讯录和日历；
- 手机上的原件**保持不动**，HomeVault 保存一份副本，服务器每晚再把它加密备份到另一块硬盘。

### 0.2 准备清单

| 需要的东西 | 从哪里来 |
|---|---|
| **访问地址**，例如 `https://192.168.1.10` 或 `https://cloud.example.com`（HTTPS 端口不是 443 时后面还有 `:端口`） | 安装总结；或让管理员运行 `sudo ./hv status`（Windows：`.\windows\hv.ps1 status`），看"访问地址"那一行 |
| 这位家人的 **Nextcloud 用户名和密码** | 管理员用 `user add` 创建，初始密码只显示一次（见 [docs/02-Linux部署.md](02-Linux部署.md) §11） |
| **身份验证器 App**（任何支持 TOTP 的都可以），并且已经绑定了这个账户 | 见下面的提示 |
| 这部手机的 **VPN 二维码** | 管理员生成，见 [§2.1](#21-管理员为这部手机生成-vpn-配置) |
| **HomeVault 根证书文件**（只有 IP 模式需要） | 管理员用 `ca` 命令导出，见 [§3](#3-安装-homevault-根证书仅-ip-模式) |
| 安卓 **9 或更高版本**的手机 | Nextcloud App 35 需要 Android 9+ |
| 两个名字：**备份文件夹名**（可以用中文，例如 `小米14-妈妈`）和 **VPN 配置名**（只能用英文字母、数字和 `-`，不超过 15 个字符，例如 `phone-mama`） | 自己起，后面会用到 |

> 💡 **第一次登录请先在电脑上完成。** HomeVault 强制所有用户使用二步验证。新账户第一次登录时要扫一个二维码来绑定身份验证器；如果在手机上操作，就变成要用这部手机去扫它自己屏幕上的二维码。所以请先在**电脑浏览器**里用新账户登录一次，用手机上的身份验证器扫码完成绑定，并把**备用码**抄下来保存好（步骤见 [docs/02-Linux部署.md](02-Linux部署.md) §10）。

## 1. 安装 App（不需要 Google Play）

### 1.1 需要安装哪些 App

| App | 作用 | 推荐下载来源 | 说明（截至 2026-09） |
|---|---|---|---|
| **Nextcloud**（包名 `com.nextcloud.client`） | 自动上传照片和文件 | ① GitHub 发布页：<https://github.com/nextcloud/android/releases>，下载名为 `nextcloud-<版本号>.apk` 的文件（35.0.0 版是 `nextcloud-350000090.apk`）；② F-Droid | 当前稳定版 **35.0.0**（2026-09-16 发布），需要 Android 9 及以上。GitHub 上另一个 `gplay-release-….apk` 是给 Google Play 用的，**不要选它**。华为应用市场里没有这个 App |
| **WG Tunnel**（包名 `com.zaneschepke.wireguardautotunnel`，**推荐**） | VPN：按 Wi-Fi 名称自动开关、自动跟随 DDNS 的 IP 变化 | ① IzzyOnDroid：<https://apt.izzysoft.de/fdroid/index/apk/com.zaneschepke.wireguardautotunnel>；② 作者自己的 F-Droid 仓库 <https://fdroid.wgtunnel.com>；③ GitHub：<https://github.com/wgtunnel/android/releases> | 当前 **5.7.4**。⚠️ F-Droid 官方仓库里的版本停在 4.1.1 很久没更新了，**不要用那个** |
| **WireGuard**（包名 `com.wireguard.android`，备选） | VPN（官方 App，功能简单） | 官网 APK：<https://download.wireguard.com/android-client/>，当前文件为 `com.wireguard.android-1.0.20260315.apk` | 当前 **1.0.20260315**，需要 Android 7.0+。已不在 F-Droid 上架；从官网安装后会**自己检查更新** |
| **DAVx⁵**（可选） | 同步通讯录和日历 | F-Droid（免费） | 只在你想让通讯录、日历和服务器双向同步时才需要，见 [§7](#7-通讯录和日历) |

**两个 VPN App 选一个即可。** 安卓同一时间只能运行一个 VPN。本文以 WG Tunnel 为主，官方 WireGuard 的用法见 [§2.3](#23-备选wireguard-官方-app)。

⚠️ **同一个 App，F-Droid 版和 GitHub 版不能互相覆盖升级**（签名不同）。想从一个来源换到另一个来源，必须先卸载，然后重新登录、重新设置自动上传。所以请一开始就选定一个来源。

### 1.2 安装 APK 的步骤

1. 用手机浏览器打开上表中的**官方地址**，下载 APK 文件。不要从来路不明的网站或"下载站"下载。
2. 打开下载好的文件。第一次安装时，系统会提示"出于安全考虑，已禁止安装未知来源的应用"之类的话，点**设置**，允许**这个浏览器**（或文件管理器）"安装未知应用"，然后返回继续安装。
3. 部分国产系统会弹出"风险提示 / 未经安全检测"的提醒，或者开启了"纯净模式""安全守护"之类的功能拦截安装。确认文件来自上面的官方地址后，选择继续安装。必要时可以临时关闭该模式，装完再打开。
4. 装好以后，建议把下载的 APK 文件删掉。

**以后怎么更新：**

| 来源 | 更新方式 |
|---|---|
| F-Droid / IzzyOnDroid / WG Tunnel 自己的 F-Droid 仓库 | 在 F-Droid 客户端里一键更新（先在 F-Droid 里添加对应仓库） |
| GitHub 发布页 | 隔一段时间回发布页下载新版本，直接覆盖安装（同一来源、签名相同，设置不会丢） |
| WireGuard 官网 APK | App 自己会提示更新 |

## 2. 导入 VPN 配置

> 在家里其实不需要 VPN。VPN 只是让手机在外面也能连回家。只打算"回到家再备份"的话，可以跳过这一步，直接看 [§3](#3-安装-homevault-根证书仅-ip-模式)。

### 2.1 管理员：为这部手机生成 VPN 配置

**每部手机一个配置，不要共用。** 设备名只用英文字母、数字和 `-`，不超过 15 个字符，例如 `phone-mama`。

- **Linux 服务器（wg-easy）：** 在电脑浏览器打开 `https://HV_HOST:8443`，登录 wg-easy → 点"新建客户端"（New Client），输入 `phone-mama` → 在列表里点这台设备的**二维码图标**。
  也可以在服务器上运行 `sudo ./hv vpn add phone-mama`，二维码会直接显示在终端里（wg-easy 启用二步验证后，这个命令不能用，改用网页）。
- **Windows 服务器：** 在管理员 PowerShell 中运行 `.\windows\hv.ps1 vpn add phone-mama`，浏览器会打开一个显示二维码的本地页面。

⚠️ **二维码里包含这部手机的 VPN 私钥。** 请让手机**直接扫电脑屏幕**，不要截图、不要拍照发到微信群或其他聊天工具。扫完后关掉二维码页面；命令行生成的 `.conf` 文件也按提示删除。

更多细节见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §4。

### 2.2 推荐：WG Tunnel

**导入：**

1. 打开 WG Tunnel，点 **+** 按钮 → **从二维码添加**，扫描电脑上的二维码。
2. 第一次打开隧道时，系统会弹出"连接请求 / 网络连接请求"对话框，点**确定 / 允许**。
3. 打开隧道开关，确认能连上（验证方法见 [§2.4](#24-验证-vpn)）。

**设置"在家自动关、出门自动开"（自动隧道）：**

在 WG Tunnel 的**自动隧道**页面：

1. 打开 **Wi-Fi 隧道**（Tunnel on Wi-Fi）：连着"不认识"的 Wi-Fi（咖啡店、公司、酒店）时自动打开隧道。
2. 打开 **允许隧道使用数据流量**（Tunnel on mobile data）：用 4G/5G 时自动打开隧道。
3. 在 **可信 WiFi 名称**（Trusted Wi-Fi）里点**添加 WiFi 名称**，输入家里的 Wi-Fi 名称（SSID）。家里有 2.4G 和 5G 两个名字、或者有多个路由器时，**每个名字都要加**。连上这些 Wi-Fi 时隧道自动关闭。
4. 按提示授予**位置权限**：选"**始终允许**"并打开"**使用精确位置**"，同时保持手机的"位置信息"开关打开。安卓规定，App 必须有这两个权限才能在后台读取 Wi-Fi 名称，否则无法判断你是不是在家。
5. 打开 **开机时启动**（Start on boot），让手机重启后自动隧道也能自动运行。
6. 点 **开启自动隧道**（Start auto-tunnel）。

**再检查几个设置：**

- **动态 DNS 自动更新**（Dynamic DNS）：保持打开。家里公网 IP 变化后，WG Tunnel 会自动更新连接地址，不需要手动重连。
- **不要**打开"**将此隧道标记为按流量计费**"：否则 Nextcloud 可能把它当作移动数据，"仅通过无流量限制的 Wi-Fi 上传"会一直等待。
- **不要**把应用模式改成"**锁定**"（Lockdown），也不要在系统 VPN 设置里勾选"**屏蔽未使用 VPN 的所有连接**"：HomeVault 的 VPN 只负责去家里的流量（分流），这两个选项会把其他所有上网流量都拦掉，手机就上不了网了。
- 应用模式保持默认的 VPN 模式即可。

> 为什么在家要关掉 VPN？在家时 VPN 要"绕到公网再回来"，很多路由器不支持这样做（NAT 回流），结果反而连不上。详见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §6。

### 2.3 备选：WireGuard 官方 App

1. 打开 WireGuard，点 **+** → **扫描二维码**，扫描电脑上的二维码。
2. 给隧道起名，例如 `homevault`。名称只能用英文字母、数字和 `_ = + . -`，最多 15 个字符。
3. 打开开关，系统弹出连接请求时点**确定**。

官方 App **不能按 Wi-Fi 名称自动开关**，你可以选择：

| 用法 | 说明 |
|---|---|
| **出门开、回家关**（手动） | 可以把 WireGuard 的开关加到下拉菜单的"快捷设置"里，方便一键切换 |
| **一直开着 + 准备一个"家里"配置** | 如果家里路由器不支持 NAT 回流，再扫一次同一个二维码，起名 `home`，编辑它，把"对端"改成 `HV_LAN_IP:WG_PORT`（例如 `192.168.1.10:34567`）。在家用 `home`，出门用 `homevault`，两个不要同时开 |
| **不开 VPN** | 只在家里备份，出门期间的照片回家后自动补传 |

⚠️ 官方 App 只在**打开隧道那一刻**解析一次域名。家里公网 IP 变了以后，需要**把隧道关掉再打开**才能连上。WG Tunnel 没有这个问题。

### 2.4 验证 VPN

1. 手机**关掉 Wi-Fi**，只用 4G/5G。
2. 打开隧道（WG Tunnel 的自动隧道此时应该已经自动打开了）。
3. 在隧道详情里看**上次握手时间**：显示"几秒之前"就说明 VPN 通了 ✔。
4. 用手机浏览器打开访问地址（例如 `https://192.168.1.10`）：
   - 域名模式：应该直接看到 Nextcloud 登录页；
   - IP 模式：在安装根证书（下一步）之前，浏览器提示"连接不是私密连接"是**正常的**。
5. 重新打开 Wi-Fi 连回家，确认 WG Tunnel 的隧道自动关闭了。

握手一直不成功？按 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §10 排查。

## 3. 安装 HomeVault 根证书（仅 IP 模式）

**先判断要不要做这一步：**

- 访问地址是 **IP**（例如 `https://192.168.1.10`）→ IP 模式，**需要**安装根证书；
- 访问地址是**域名**（例如 `https://cloud.example.com`）→ 域名模式，证书由公共机构签发，**跳过这一步**，直接看 [§4](#4-登录-nextcloud-app)。

IP 模式下，HomeVault 用自己的"本地证书机构"（HomeVault Local CA）给服务器签发证书。手机要先"认识"这个证书机构，才会信任服务器。Nextcloud 安卓 App 和 Chrome 浏览器都信任用户自行安装的 CA 证书。

### 3.1 拿到证书文件和指纹

管理员在服务器上运行：

```bash
sudo ./hv ca                          # Linux：导出根证书，显示 SHA-256 指纹
sudo ./hv ca --export /tmp/HomeVault-CA.crt   # 或者导出到指定位置
```

```powershell
.\windows\hv.ps1 ca                   # Windows
```

命令会显示证书文件的保存位置和一串 **SHA-256 指纹**（形如 `3A:7F:…:C2`，共 32 组）。**把指纹抄下来或拍下来**，第 3.3 步核对要用。

把 `.crt` 文件传到手机上，任选一种方式：

- **方法 A（推荐）：数据线。** 手机用 USB 线连电脑，选"传输文件"，把 `.crt` 文件复制到手机的 `Download`（下载）文件夹。
- **方法 B：管理面板下载。** 手机连着家里 Wi-Fi（或已连 VPN），浏览器打开 `https://HV_HOST:9443/ca.crt`（9443 是管理面板端口 `HV_PANEL_PORT` 的默认值）。因为手机这时还不信任 HomeVault 的证书，浏览器会提示"连接不是私密连接"：**仅限这一次、仅为下载这个文件**，可以点"高级 → 继续前往"。如果浏览器不允许继续，请改用方法 A。
- **方法 C：聊天工具或网盘。** 根证书文件本身**不是机密**（真正要保密的是服务器上的私钥），用微信、QQ 发送也可以。在聊天工具里先选"保存到手机"或"用其他应用打开"，确保文件出现在手机的"下载"文件夹里。

⚠️ 不管用哪种方法拿到文件，**都必须在第 3.3 步核对指纹**。这是确认"这确实是你家服务器的证书、没有被调包"的唯一办法。

### 3.2 安装证书

安卓 11 起，CA 证书**只能在系统设置里安装**：在文件管理器里直接点 `.crt` 文件不会安装 CA 证书。

**原生安卓（Pixel 等）的路径：**

> 设置 → **安全和隐私** → **更多安全和隐私设置**（有的版本叫"更多安全设置"）→ **加密与凭据** → **安装证书** → **CA 证书** → 看到"**您的数据将不再是私密的**"提示 → **仍然安装** → 验证锁屏密码 → 选择刚才的 `.crt` 文件

较老的版本是：设置 → **安全** → **加密与凭据** → 安装证书 → CA 证书。

**国产手机（小米/Redmi 的 HyperOS 和 MIUI、OPPO/一加/realme 的 ColorOS、vivo/iQOO 的 OriginOS、华为/荣耀的 EMUI 等）：**

菜单位置各家不同，也会随系统版本变化。最可靠的办法是：

1. 打开**设置**，在顶部的**搜索框**里输入"**证书**"（也可以试"CA 证书""加密与凭据""凭据"）；
2. 在搜索结果里选"**安装证书**"或"**从存储设备安装**"；
3. 选择"**CA 证书**"（不要选"VPN 和应用用户证书"或"WLAN 证书"）；
4. 确认风险提示，选择"仍然安装"，然后选择 `.crt` 文件。

注意事项：

- 手机必须设置了**锁屏密码 / PIN / 图案**，否则系统不允许安装证书。
- 部分系统安装后会显示"网络可能受到监控"之类的提示。这是系统对用户自行安装证书的常规提醒，属于正常现象。

### 3.3 核对指纹（不要跳过）

1. 设置 → 搜索"**可信凭据**"（原生安卓路径：加密与凭据 → **可信凭据**）；
2. 切到"**用户**"标签页，找到名字类似"**HomeVault Local CA - 2026 ECC Root**"的证书（年份是证书生成的年份），点开；
3. 在详情里找到"**SHA-256 指纹：**"，和 3.1 步抄下的指纹**逐段对比**。

- 完全一致 ✔：可以继续；
- 不一致 ✘：**立即**在同一页面点"**卸载**"删除这个证书，并告诉管理员。

⚠️ **关于根证书的安全提醒：**

- 安装了这个根证书的手机，会信任它签发的**任何**网站证书。掌握 HomeVault 服务器上根私钥的人，理论上可以冒充任何网站。所以：
  - 只给**自家人的设备**安装；
  - 保护好服务器和备份（详见 [docs/01-架构与安全.md](01-架构与安全.md) §3.6）；
  - 手机卖掉、送人或恢复出厂前，到"可信凭据 → 用户"里把它**卸载**。
- 服务器重装时，如果没有从备份恢复 Caddy 数据，会生成一个**新的**根证书。那时所有设备都要删除旧证书、安装新证书。
- 有自己的域名时，改用**域名模式**，就完全不需要在手机上安装证书。

## 4. 登录 Nextcloud App

1. **确认网络：** 在家连着家里 Wi-Fi；或者在外面、VPN 已连上。
2. 打开 Nextcloud App，点"**登录**"。
3. 在"**服务器地址**"里填访问地址，**一个字都不要差**：
   - 例如 `https://192.168.1.10` 或 `https://cloud.example.com`；
   - HTTPS 端口不是 443 时要带端口，例如 `https://192.168.1.10:4443`；
   - ⚠️ **不要**填 VPN 地址（例如 `10.99.77.1`）或 DDNS 域名（`WG_HOST`）。在家和在外都用同一个访问地址，App 以后永远不需要改。
4. App 会打开 Nextcloud 的登录页面，显示"**连接到您的账号**"。点"**登录**"，输入用户名和密码。
5. 输入身份验证器 App 里的 **6 位验证码**。
6. 点"**授权访问**"，看到"**账号已连接**"后会自动回到 App。

完成后：

- App 自动获得一个**专属应用密码**。你的登录密码不会保存在手机上。
- 在网页版的 头像 → **个人设置** → **安全** → **设备和活动链接** 里能看到这部手机。手机丢了，就在这里撤销它（见 [§9](#9-手机丢了或换新手机)）。

**如果 App 弹出"是否信任此证书？"：**

⚠️ **请不要点信任。** 这说明根证书没有装好（IP 模式），或者你填的地址不对。对话框里显示的是服务器的"网站证书"，它的有效期只有 12 小时，Caddy 会不断自动更换。现在点了信任，过不了多久又会报错。请回到 [§3](#3-安装-homevault-根证书仅-ip-模式) 装好根证书，再重新登录。

**其他常见提示：**

| 提示 | 原因 | 办法 |
|---|---|---|
| "请输入有效的服务器地址" / 连接超时 | 网络不通：在外面没开 VPN；在家连的是访客 Wi-Fi | 连上家里的主 Wi-Fi 或打开 VPN 后再试 |
| "通过不受信任的域名访问" | 服务器地址填成了访问地址以外的地址 | 改用访问地址；仍不行请管理员检查 `HV_TRUSTED_DOMAINS` |
| 登录页要求绑定二步验证、显示一个二维码 | 这个账户还没绑定身份验证器 | 先在电脑上完成首次登录和绑定（见 [§0.2](#02-准备清单) 的提示） |

## 5. 设置自动上传（核心步骤）

### 5.1 先规划：备份到哪里

建议所有手机都备份到 `/手机备份/<设备名>/` 下面，每类内容一个子文件夹：

| 手机上的文件夹（本地文件夹） | 里面是什么 | 备份到（远端文件夹） | 怎么添加 |
|---|---|---|---|
| `DCIM/Camera` | 相机拍的照片和视频 | `/手机备份/小米14-妈妈/相机` | 自动识别的媒体文件夹 |
| `DCIM/Screenshots` 或 `Pictures/Screenshots`（因品牌而异） | 截图 | `/手机备份/小米14-妈妈/截图` | 自动识别的媒体文件夹 |
| `Pictures/WeiXin` | 在微信里"保存到手机"的图片和视频 | `/手机备份/小米14-妈妈/微信` | 自动识别的媒体文件夹 |
| `Download` | 浏览器和各种 App 下载的文件 | `/手机备份/小米14-妈妈/下载` | 自定义文件夹 |
| `Documents` | 文档 | `/手机备份/小米14-妈妈/文档` | 自定义文件夹 |

为什么这样分：

- **每部手机一个文件夹**：不同手机的照片经常同名（例如 `IMG_20260101_120000.jpg`），分开放不会互相冲突；换手机或清理时也一目了然。
- 在 App 里选择远端文件夹时，可以直接新建文件夹，不需要事先在网页上创建。

> 微信聊天里收到的文件（文档、压缩包等）默认存放在微信自己的目录里，新版安卓不允许其他 App 读取。想备份的文件，请在微信里先"保存到手机"或"用其他应用打开"，存到"下载"文件夹，它就会被 `Download` 这一项备份。

### 5.2 打开自动上传

1. 在 Nextcloud App 里点左上角的菜单（☰）→ **自动上传**。
2. 第一次打开时，App 会请求存储权限。请选择"**所有文件访问权限**"并在系统页面里允许。
   只给"媒体只读权限"的话，只能备份照片和视频，`Download`、`Documents` 这类文件夹就备份不了。
3. 页面上会列出 App 自动发现的媒体文件夹（相机、Screenshots、WeiXin 等）。每个文件夹右边有开关和"⋮"菜单。
4. 手机 `Download`、`Documents` 这类非媒体文件夹不在列表里：点右上角的"⋮"→ **设置一个自定义文件夹**。

### 5.3 每个文件夹的设置（逐项说明）

点文件夹右边的"⋮"→ **配置**，逐项设置如下。App 的中文界面和英文界面名称都列出来了，方便对照。

| 选项（中文界面） | 英文界面 | 建议 | 说明 |
|---|---|---|---|
| **本地文件夹** | Local folder | 按 §5.1 的表 | 手机上要备份的文件夹 |
| **远端文件夹** | Remote folder | `/手机备份/<设备名>/相机` 等 | 点"选择远程文件夹…"，可以在里面新建文件夹。默认值是 `/实时上传`，请改掉 |
| **仅通过无流量限制的 Wi-Fi 上传** | Only upload on unmetered Wi-Fi | **建议打开**（尤其是相机） | 用 4G/5G 时先不传，连上 Wi-Fi 后自动补传。流量充足、希望出门也实时备份的，可以关掉 |
| **仅在充电时上传** | Only upload when charging | 可选 | 每天晚上充电时统一上传，最省电。首次全量上传时建议打开 |
| **同时上传现有文件** | Also upload existing files | **首次设置时打开** | 不打开的话，**只有打开自动上传之后新拍的照片**才会上传，以前的照片不会备份 |
| **使用子文件夹** / **依据日期存储在子文件夹內** | Use subfolders / Store in subfolders based on date | 相机、截图**建议打开** | 按日期自动建子文件夹。在"**子文件夹选项**"（Subfolder options）里选按"年/月"，每个文件夹里的文件数适中，网页和电脑上浏览都更快 |
| **排除隐藏** | Exclude hidden | 打开 | 不上传以"."开头的隐藏文件和文件夹（多为缓存） |
| **原始文件将会被…** | Original file will be… | ⚠️ **保留在原始文件夹** | 见下方警告 |
| **如果文件已经存在怎么办？** | What to do if the file already exists? | **重命名新版本** | 永远不会覆盖服务器上已有的文件，也不会漏传。重新安装 App 后重新设置时，可以改选"跳过上传"，避免产生重复文件 |

⚠️ **"原始文件将会被…"一定要选"保留在原始文件夹"。**

- **不要**选"被删除"或"移动到应用文件夹"：一旦上传过程或服务器出了问题，手机上就再也找不到原件了。
- 35.0.0 版还新增了"**Locally delete uploaded files**"（删除本机已上传的文件）功能，用来腾出手机空间。在你**亲自确认过网页上的文件完好、并且服务器的每晚备份正常**（[§8](#8-确认备份真的成功了)）之前，请不要使用。
- 手机里的原件 + HomeVault 上的副本 + 服务器的加密备份，才是完整的"多份备份"。

⚠️ **不要让文件夹互相包含。** 例如同时给 `DCIM` 和 `DCIM/Camera` 打开自动上传，App 会提示"此文件夹已包含在上级文件夹的同步中，这可能会导致重复上传"。每个文件只应该属于一个自动上传项。

设置完成后，确认每个文件夹右边的**开关是打开的**。

### 5.4 第一次全量上传

手机里可能已经存了几十 GB 的照片和视频，第一次上传需要一段时间：

1. **在家、连着 Wi-Fi、插着充电器**进行，最好放一个晚上。
2. 想立刻开始，可以在自动上传页面点 **Sync now**（35.0.0 新增的"立即同步"按钮，目前界面上显示的是英文）。
3. 在菜单（☰）→ **上传** 里查看进度。
4. 在外面通过 VPN 上传时，速度受家里宽带的**上行**带宽限制（通常比下行小得多）。大批量的上传尽量放在家里做。

### 5.5 大视频

- Nextcloud App 采用**分块上传**，HomeVault 服务器允许单个文件达到数 GB（`PHP_UPLOAD_LIMIT=16G`，中间的 Caddy 不限制请求大小），4K 视频也能正常备份。
- 网络中断时，App 会自动重试。
- 录了很多大视频的话，建议相机文件夹打开"仅通过无流量限制的 Wi-Fi 上传"。

### 5.6 查看上传状态

在菜单（☰）→ **上传** 页面可以看到每个文件的状态，常见的有：

| 状态 | 含义 |
|---|---|
| **等待非流量计费的 Wi-Fi 连接** | 打开了"仅 Wi-Fi 上传"，正在等 Wi-Fi，正常 |
| **等待充电** | 打开了"仅在充电时上传"，正常 |
| **不受信任的服务器证书** | 根证书没装好，见 [§3](#3-安装-homevault-根证书仅-ip-模式) |
| **上传失败，请重新登录** | 这部手机的授权被撤销了，或密码被重置了，重新登录即可 |
| **上传已停止 — 需要存储权限** | 存储权限被系统收回了，点通知重新授权 |

App 在自动上传页面顶部还可能显示"**Nextcloud 的后台活动受到电池优化的限制。**"或"**省电模式已开启，可能会暂停上传。**"。请点旁边的"**允许后台活动**"或"**打开省电模式设置**"处理，然后完成下一节的设置。

## 6. 防止系统杀后台（非常重要）

国产手机系统为了省电，会很积极地关闭后台 App。知名的 dontkillmyapp 网站给小米、华为、三星的"杀后台"程度都打了最高的 5 分。结果就是：**你不打开 Nextcloud，它就不上传**；VPN 也可能被悄悄关掉。

**要设置的 App：** Nextcloud、WG Tunnel（或 WireGuard）、DAVx⁵（如果装了）。**每个 App 都要设置**以下 4 项：

| 设置 | 作用 |
|---|---|
| **允许自启动**（有的系统还有"关联启动"，也要允许） | 手机重启后或被系统唤醒时能自己运行 |
| **电池 / 耗电策略设为"无限制"**（或"允许后台高耗电""不优化"） | 不被省电机制暂停 |
| **在最近任务里锁定** | 一键清理后台时不被清掉 |
| **允许通知** | 上传和 VPN 在后台运行时需要显示一个常驻通知，关掉通知可能导致被系统停止 |

下面是各品牌的**常见位置**。系统版本不同，菜单名称会略有差异；找不到时，在"设置"顶部的搜索框里搜表中的关键词。

### 6.1 小米 / Redmi（HyperOS、MIUI）

| 设置 | 常见位置 |
|---|---|
| 自启动 | 设置 → 应用设置 → 应用管理 → Nextcloud → 打开"**自启动**" |
| 省电策略 | 同一页面 → **省电策略** → 选"**无限制**" |
| 锁定 | 打开最近任务 → **长按** Nextcloud 的卡片 → 点锁形图标 |
| 通知 | 同一应用详情页 → 通知管理 → 允许通知 |
| 搜索关键词 | 自启动、省电策略 |

### 6.2 华为 / 荣耀（EMUI、HarmonyOS 2–4、MagicOS）

| 设置 | 常见位置 |
|---|---|
| 自启动 + 后台运行 | 设置 → 电池 → **应用启动管理** → 找到 Nextcloud → 关闭"**自动管理**" → 在弹出的窗口里打开"**允许自启动**""**允许关联启动**""**允许后台活动**" |
| 锁定 | 打开最近任务 → 把 Nextcloud 的卡片**往下拉**，出现锁形图标 |
| 通知 | 设置 → 通知 → Nextcloud → 允许通知 |
| 搜索关键词 | 应用启动管理、启动管理 |

HarmonyOS NEXT（HarmonyOS 5 及以后）不能安装安卓 App，见 [§10](#10-华为-harmonyos-next-用户)。

### 6.3 OPPO / 一加 / realme（ColorOS、OxygenOS、realme UI）

| 设置 | 常见位置 |
|---|---|
| 自启动 + 后台运行 | 设置 → 应用 → 应用管理 → Nextcloud → **耗电管理**（或"电池使用"）→ 打开"**允许完全后台行为**""**允许自动启动**""**允许关联启动**" |
| 电池优化（部分版本） | 设置 → 电池 → 更多设置 → **优化电池使用** → Nextcloud → 不优化 |
| 锁定 | 打开最近任务 → 点卡片右上角的"⋮"或长按卡片 → **锁定** |
| 搜索关键词 | 耗电管理、自启动、后台 |

### 6.4 vivo / iQOO（OriginOS、Funtouch OS）

| 设置 | 常见位置 |
|---|---|
| 后台耗电 | 设置 → 电池 → **后台耗电管理** → Nextcloud → 选"**允许后台高耗电**" |
| 自启动 | 设置 → 应用与权限 → 权限管理 → **自启动** → 打开 Nextcloud（或 i管家 → 应用管理 → 自启动管理） |
| 锁定 | 打开最近任务 → 把卡片**往下拉**锁定 |
| 搜索关键词 | 后台耗电管理、自启动 |

### 6.5 三星（One UI）

| 设置 | 常见位置 |
|---|---|
| 电池 | 设置 → 应用程序 → Nextcloud → 电池 → 选"**不受限制**" |
| 睡眠名单 | 设置 → 电池（和设备维护）→ **后台使用限制** → 把 Nextcloud 等 App 加入"**从不休眠的应用程序**"；确认它们不在"睡眠应用程序"或"深度睡眠应用程序"名单里 |
| 锁定 | 打开最近任务 → 点 App 图标 → **锁定此应用** |
| 搜索关键词 | 从不休眠、后台使用限制 |

### 6.6 原生安卓及其他品牌

- 设置 → 应用 → Nextcloud → **电池**（应用电池用量）→ 选"**无限制**"；
- 如果有"**未使用时暂停应用活动**""**移除未使用应用的权限**"之类的开关，对这几个 App 关掉。不然长期不打开的 App 会被系统收回权限，WG Tunnel 就读不到 Wi-Fi 名称了。

### 6.7 设置核对表

| | Nextcloud | WG Tunnel / WireGuard | DAVx⁵ |
|---|---|---|---|
| 自启动 / 关联启动 | ☐ | ☐ | ☐ |
| 电池"无限制" | ☐ | ☐ | ☐ |
| 最近任务锁定 | ☐ | ☐ | ☐ |
| 通知允许 | ☐ | ☐ | ☐ |
| 位置"始终允许" + 精确位置 | — | ☐（仅 WG Tunnel） | — |

**检验方法：** 设置完后，把手机锁屏放一个小时，然后拍一张照片，再锁屏等 10–20 分钟，不要打开 Nextcloud。之后在电脑网页上看这张照片有没有出现在备份文件夹里（相机文件夹开了"仅 Wi-Fi 上传"的话，测试时要连着 Wi-Fi）。

## 7. 通讯录和日历

有两种方式，可以只用一种，也可以都用：

| 方式 | 效果 | 适合 |
|---|---|---|
| **A. Nextcloud App 自带的"通讯录和日历备份"** | 每天把手机上的通讯录和日历**导出一份**，保存到 Nextcloud。单向备份 | 只想"有个备份以防万一"，最简单 |
| **B. DAVx⁵ 双向同步** | 通讯录和日历**以服务器为准**，手机、网页、电脑上的修改互相同步 | 想在多台设备间共用通讯录和日历 |

### 7.1 方式 A：Nextcloud App 自带备份

1. Nextcloud App → 菜单（☰）→ 设置 → **通讯录和日历备份**；
2. 打开"**每日备份**"，然后点"**现在备份**"立即备份一次；
3. 换手机或需要找回时，在同一页面选择一份备份，用"**恢复联系人和日历**"导回手机。

### 7.2 方式 B：DAVx⁵ 双向同步

先从 F-Droid 安装 DAVx⁵，然后三选一：

**① 最省事：从 Nextcloud App 一键设置**

Nextcloud App → 设置 → **同步日历和联系人**（为当前账号设置 DAVx⁵）。按提示跳转到 DAVx⁵ 完成添加，不需要另外输入密码。

**② 在 DAVx⁵ 里用 Nextcloud 登录流程**

DAVx⁵ → 添加账户 → 选"**Nextcloud**"（Login with Nextcloud）→ 服务器地址填访问地址（例如 `https://192.168.1.10`）→ 在打开的网页里登录、输入验证码、点"授权访问"。

**③ 手动填写地址和应用密码**

1. 先在网页版创建一个**应用密码**：头像 → **个人设置** → **安全** → 页面底部"**应用的名称**"填 `DAVx5-妈妈手机` → 点"**创建新应用密码**" → 复制显示的密码（只显示一次）。
2. DAVx⁵ → 添加账户 → "**使用 URL 和用户名登录**"（Login with URL and user name）：
   - Base URL：`https://HV_HOST/remote.php/dav`（例如 `https://192.168.1.10/remote.php/dav`；HTTPS 端口不是 443 时带上端口）
   - 用户名：你的 Nextcloud **用户名**（登录名，不是显示名）
   - 密码：刚才的**应用密码**（启用二步验证后，登录密码在这里不能用）

**添加账户之后：**

1. 在 DAVx⁵ 里勾选要同步的**通讯录**和**日历**；
2. ⚠️ **把手机上已有的联系人搬进 DAVx⁵ 账户。** 只有保存在 DAVx⁵ 账户里的联系人才会同步到服务器，保存在"手机""本机"或其他账户里的不会。做法：在手机的"联系人"App 里把现有联系人**导出**为 `.vcf` 文件，再**导入**到 DAVx⁵ 的通讯录账户中；
3. 在"联系人"App 的设置里，把**新建联系人的默认保存位置**设为 DAVx⁵ 账户；
4. 日历同理：新建日程时选择 DAVx⁵ 同步的那个日历；
5. 别忘了按 [§6](#6-防止系统杀后台非常重要) 给 DAVx⁵ 也设置自启动和电池"无限制"。

IP 模式下，DAVx⁵ 使用手机里已安装的 HomeVault 根证书。如果 DAVx⁵ 弹窗询问是否信任某个证书，请先确认 [§3](#3-安装-homevault-根证书仅-ip-模式) 已完成，不要随手点接受。

## 8. 确认备份真的成功了

设置完成后当天检查一次，以后**每月检查一次**。

1. **看网页：** 在电脑浏览器打开访问地址 → **文件** → `手机备份` → `<设备名>` → `相机`。最近拍的照片应该都在，数量和手机相册大致相当。
2. **看 App：** Nextcloud App → 菜单 → **上传**，没有长期处于"失败"状态的文件。
3. **看服务器备份（管理员）：** Nextcloud 里的文件还只是"第二份"，服务器每晚还会用 restic 加密备份到另一块硬盘。
   - `sudo ./hv status`（Windows：`.\windows\hv.ps1 status`）会显示"最近一次成功备份"的时间；
   - `sudo ./hv doctor`（Windows：`.\windows\hv.ps1 doctor`）会检查最近一次备份是否在 48 小时以内，超过就显示 ✘。
4. **做一次恢复演练：** 在网页上随便挑一张照片**下载**到电脑，确认能正常打开。从服务器备份里找回文件的演练，见 [docs/07-备份与恢复.md](07-备份与恢复.md)。

## 9. 手机丢了或换新手机

**手机丢了**，越快处理越好（完整步骤见 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §10）：

1. 在电脑上登录网页 → 头像 → **个人设置** → **安全** → **设备和活动链接**，找到丢失的手机，选"**撤销**"；有"**擦除设备**"时可以选它：手机下次联网时，Nextcloud App 会删除它自己的数据和登录信息（不会删除相册里的照片）。DAVx⁵ 用的应用密码也在这里一并撤销。
2. 删除这部手机的 VPN 配置：
   - Linux：在 wg-easy 网页上删除这个客户端；
   - Windows：`.\windows\hv.ps1 vpn remove phone-mama`。
3. 如果身份验证器也装在这部手机上：用**备用码**登录后重新绑定，或者请管理员执行 `sudo ./hv user reset-2fa <用户名>`（Windows：`.\windows\hv.ps1 user reset-2fa <用户名>`）。

**换新手机：**

- 按本文从头设置一遍，使用**新的** VPN 配置（新设备名，例如 `phone-mama2`），备份到**新的**设备文件夹（例如 `/手机备份/小米15-妈妈/`）。旧手机的文件夹原样保留，作为归档。
- 旧手机上的 VPN 配置和 Nextcloud 登录，按"手机丢了"的第 1、2 步撤销；然后删除旧手机上的 HomeVault 根证书，再恢复出厂设置。
- 想把旧照片放回新手机：在 Nextcloud App 或网页上选中文件下载即可。通讯录和日历用 [§7](#7-通讯录和日历) 的方式恢复。

## 10. 华为 HarmonyOS NEXT 用户

**HarmonyOS NEXT（HarmonyOS 5 及以后的版本）不能安装和运行安卓 APK**，所以 Nextcloud、WireGuard、WG Tunnel 的安卓 App 都无法使用。HarmonyOS 4.x 及更早的版本仍然可以安装 APK，按本文正常设置即可。

在 HarmonyOS NEXT 手机上可以：

- **用浏览器上传：** 在家连着 Wi-Fi 时，用浏览器打开访问地址登录，在"文件"里进入 `/手机备份/<设备名>/`，点"+"→ 上传文件，手动选择照片上传。IP 模式下需要先按系统的方法安装 HomeVault 根证书，否则浏览器会报证书错误。
- **用支持 WebDAV 的文件管理 App**（如果应用市场里有）：地址填 `https://HV_HOST/remote.php/dav/files/<用户名>/`，密码用网页上创建的**应用密码**（创建方法见 [§7.2](#72-方式-bdavx⁵-双向同步) 第 ③ 种方式）。
- **外出时无法连回家**：没有可用的 WireGuard 客户端，只能回家后再上传。

依赖自动备份的家人，升级到 HarmonyOS NEXT 之前请先考虑清楚。

## 11. 附：HomeVault 管理 App（可选，给管理员）

HomeVault 另外提供一个安卓 App"**HomeVault 家庭归档**"，用来在手机上查看服务器状态、硬盘空间、备份记录和日志。它只是管理面板的手机外壳，**和照片备份无关**，家人不需要安装。下载方式：在管理面板（`https://HV_HOST:9443`）的"设置"页扫描下载二维码。IP 模式下同样依赖本文 [§3](#3-安装-homevault-根证书仅-ip-模式) 安装的根证书。

## 12. 排错

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| **"不受信任的服务器证书"** / 弹出"是否信任此证书？" | IP 模式下没装根证书，或装错了位置（装成了"VPN 和应用用户证书"） | 按 [§3](#3-安装-homevault-根证书仅-ip-模式) 以"CA 证书"类型安装，并在"可信凭据 → 用户"里核对指纹。不要点"信任" |
| 以前正常，突然全部证书报错 | 服务器重装后生成了新的根证书；或者手机日期时间错了 | 安装新根证书并删除旧的；打开"自动设置日期和时间" |
| 证书错误，提示"网址与证书中的主机名不匹配" | 服务器地址填的不是访问地址（例如填了 VPN 地址或公网域名） | 退出账号，用访问地址重新登录 |
| **在家时连接超时** | ① VPN 在家也开着，路由器不支持 NAT 回流；② 连的是访客 Wi-Fi（和主网络隔离）；③ 服务器关机或睡眠；④ 域名模式下路由器的 DNS 重绑定保护 | ① 设置 WG Tunnel 可信 Wi-Fi（[§2.2](#22-推荐wg-tunnel)），或在家关掉 VPN；② 连主 Wi-Fi；③ 检查服务器；④ 见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §6.1 |
| **在外面连接超时** | VPN 没打开或握手失败；家里公网 IP 刚变过（官方 WireGuard App 需要重开隧道） | 看 VPN App 里的"上次握手时间"；按 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §10 排查 |
| **上传一直显示"等待"** | 打开了"仅 Wi-Fi 上传"或"仅充电时上传"，条件还没满足；省电模式开着 | 连 Wi-Fi / 插上充电器；关闭省电模式，或在 App 提示里点"允许后台活动" |
| 连着 Wi-Fi，却一直"等待非流量计费的 Wi-Fi 连接" | WG Tunnel 打开了"将此隧道标记为按流量计费"；或者这个 Wi-Fi 在手机设置里被标记为"按流量计费"（例如手机热点） | 关闭该选项；在该 Wi-Fi 的详细设置里把"计费方式"改为"不按流量计费" |
| **只在打开 App 时才上传**，或隔很久才上传 | 被系统杀了后台 | 按 [§6](#6-防止系统杀后台非常重要) 把 4 项设置都做好，Nextcloud 和 VPN App 都要设置 |
| 以前的照片没有上传，只有新照片上传了 | 没打开"同时上传现有文件" | 在该文件夹的配置里打开它 |
| 某个文件夹完全没有上传 | 文件夹的开关没打开；只给了"媒体只读权限"，却想备份 `Download` 这类文件夹 | 打开开关；改成"所有文件访问权限" |
| **"上传已停止 — 需要存储权限"** | 系统收回了存储权限（长期未使用或系统更新后） | 点通知重新授权；关闭"未使用时移除权限" |
| **耗电明显增加** | 首次全量上传期间耗电大是正常的；长期耗电大可能是 VPN 保活或频繁重试 | 相机开"仅 Wi-Fi 上传"或"仅充电时上传"；VPN 保活保持 0（默认）；用 WG Tunnel 在家自动关闭 VPN |
| **大视频上传失败**或反复重传 | 在外面网络不稳定；VPN 的 MTU 偏小；服务器硬盘满了 | 大视频放在家里 Wi-Fi 下传；在 VPN App 里把 MTU 改成 1280 试试；请管理员用 `doctor` 检查剩余空间 |
| **出现重复文件**（例如 `IMG_1234 (2).jpg`） | ① 两个自动上传项互相包含（`DCIM` 和 `DCIM/Camera`）；② 重装 App 后打开了"同时上传现有文件"；③ 两部手机备份到了同一个文件夹 | ① 只保留一项；② 重新设置时"如果文件已经存在"改选"跳过上传"；③ 每部手机用自己的文件夹 |
| **"上传失败，请重新登录"** | 这部手机的授权被撤销，或者密码被重置 | 在 App 里重新登录 |
| 通讯录没有同步到服务器 | 联系人保存在"手机 / 本机"账户，不在 DAVx⁵ 账户里 | 按 [§7.2](#72-方式-bdavx⁵-双向同步) 导出再导入，并修改默认保存位置 |
| 手机重启后 VPN 不自动运行 | WG Tunnel 没开"开机时启动"；没有自启动权限 | 打开"开机时启动"；按 [§6](#6-防止系统杀后台非常重要) 允许自启动 |

更多问题见 [docs/09-常见问题.md](09-常见问题.md)。
