## 1. 安装

### 1.1 国内拉取镜像失败，提示连接超时或 `pull access denied`？

从 2024 年 6 月起，中国大陆基本无法直接访问 Docker Hub（`docker.io`），`ghcr.io` 也经常连不上。安装时加上镜像参数：

```bash
sudo ./hv install --mirror daocloud      # 使用 DaoCloud 公共镜像
sudo ./hv install --mirror custom        # 或者自己输入 docker.io 和 ghcr.io 的替换前缀
```

Windows 同样是 `.\windows\hv.ps1 install --mirror daocloud`。已经装好的，重新运行一次带 `--mirror` 的安装即可，不会影响数据和密码。

- 它会把 `.env` 里所有 `*_IMAGE` 镜像地址换成镜像站前缀。管理面板镜像是在本机构建的，构建用的 Go 基础镜像也会走同一个前缀；域名模式构建 Caddy 时，Go 模块代理会改用 `https://goproxy.cn`；
- Docker 自带的 `registry-mirrors` 设置**只对 docker.io 有效**，wg-easy 等 `ghcr.io` 上的镜像仍需要 `--mirror`；
- 公共镜像站有白名单和限流，偶尔会失败。稍后重试，或者换一个你信任的镜像站（`--mirror custom`）。

详见 [docs/02-Linux部署.md](02-Linux部署.md) §3、[docs/03-Windows部署.md](03-Windows部署.md) §3.5。

### 1.2 安装时提示"端口已被占用"？

HomeVault 默认使用 TCP 80（跳转到 HTTPS）、443（Nextcloud）、8443（Linux 的 VPN 管理页）、9443（管理面板）。被别的程序占用时，可以换端口：

```bash
sudo ./hv install --https-port 8444 --http-port 8080 --panel-port 9444
```

注意：HTTPS 端口不是 443 时，访问地址会带上端口号（例如 `https://192.168.1.10:8444`），手机和电脑里都要用这个完整地址。能释放 443 的话最好还是用 443。

### 1.3 重新运行安装程序，会不会覆盖我的数据和密码？

不会。`install` 可以放心重复运行：已有的 `secrets/` 密码文件不会重新生成，`.env` 里已有的设置会作为默认值，Nextcloud 数据也不会被动。修改设置、换镜像站、升级 HomeVault 套件后，都可以重新运行一次安装。

### 1.4 Windows：双击"一键安装.cmd"后没反应，或提示"禁止运行脚本"？

- 双击后会弹出"用户账户控制"（UAC）窗口，要点"**是**"。Windows SmartScreen 提示"已保护你的电脑"时，点"更多信息 → 仍要运行"；
- 从网上下载的 ZIP 解压出来的文件带有"来自网络"标记，可能被拦截。在 HomeVault 文件夹里用管理员 PowerShell 运行一次：`Get-ChildItem -Recurse | Unblock-File`；
- 也可以不用双击，直接在管理员 PowerShell 里运行：

  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\hv.ps1 install
  ```

### 1.5 Windows 家庭版能用吗？

能。家庭版也可以用 WSL2 运行 Docker Desktop。区别是：家庭版没有完整的 BitLocker（只有"设备加密"，不能加密 USB 移动硬盘），也没有 Hyper-V。电脑必须一直登录着 HomeVault 专用账户（自动登录 + 自动锁屏），见 [docs/03-Windows部署.md](03-Windows部署.md) §7。

### 1.6 忘记了 Nextcloud 管理员密码，或者手机丢了登不上两步验证？

```bash
sudo ./hv user reset-password hvadmin    # 生成新密码，只显示一次
sudo ./hv user reset-2fa hvadmin         # 清除两步验证，下次登录时重新绑定
```

把 `hvadmin` 换成对应的用户名。家人忘了密码，管理员也用同样的命令帮他重置。两步验证还可以用绑定时保存的**备用码**登录。

## 2. 网络与 VPN

### 2.1 怎样确认家里有公网 IPv4？

对比两个地址：路由器（或光猫）WAN 口显示的 IP，和在家里电脑上执行 `curl -4 https://4.ipw.cn` 看到的 IP。两者**相同**，说明有公网 IP；WAN 口是 `100.64.x.x`–`100.127.x.x` 或 `10.x`、`192.168.x` 这类地址，说明你在运营商的 NAT 后面，外面连不进来。可以打电话给运营商（电信 10000、联通 10010、移动 10086）申请"动态公网 IP"。详见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §1。

### 2.2 运营商不给公网 IP，还能在外面备份吗？

HomeVault 自带的 WireGuard 方案需要公网 IPv4。没有的话，可以用 Tailscale、ZeroTier 等"组网"工具替代 VPN 部分，见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §9。或者只在家里备份：在外面时自动上传会失败并自动重试，回家连上 Wi-Fi 后就会传上去。

### 2.3 为什么路由器只转发一个 UDP 端口，不能直接转发 443 或者开 DMZ？

安全。外面的人只能看到一个 WireGuard 端口，没有正确的密钥，WireGuard 对任何数据包都不回应，扫描器甚至不知道这里有服务。Nextcloud、管理面板都**只在家里局域网和 VPN 里**能访问。DMZ 会把电脑的所有端口都暴露到公网，绝对不要开。另外，国内家庭宽带的 80、443 端口通常也被运营商封了。

### 2.4 在家连着 Wi-Fi 时开着 VPN，就打不开 Nextcloud？

这是路由器不支持"NAT 回流"导致的：手机在家里却绕到公网地址再回来，很多家用路由器不支持。最省心的做法是用 **WG Tunnel**，把家里的 Wi-Fi 设为"可信网络"，在家自动断开 VPN、出门自动连上。详见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §6。

### 2.5 家里的公网 IP 变了以后，手机连不上了？

- 先确认 DDNS 已更新：`sudo ./hv ddns status`，对比域名解析到的 IP 和当前公网 IP；
- 官方 WireGuard App 只在打开隧道时解析一次域名，IP 变了要**关掉隧道再打开**；WG Tunnel 会自动跟随，所以更推荐它。

### 2.6 在公司、酒店的 Wi-Fi 下连不上 VPN，4G 却可以？

可能是这个网络屏蔽了 UDP 或这个端口，或者需要先在网页上登录认证。先完成网页认证；不行就切到 4G。如果你的 VPN 选择了"访问整个家庭局域网"，而对方网络和你家用的是同一个网段（都是 `192.168.1.x`），也会冲突，见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §7。

### 2.7 连上 VPN 后，能访问家里的路由器、NAS 等其他设备吗？

默认**不能**，只能访问 HomeVault 这台主机（`HV_VPN_LAN_ACCESS=host`）。这样即使一部手机丢了、VPN 配置泄露，别人也只能碰到一台开了两步验证的服务器。确实需要时，Linux 版可以改成 `full`，方法和风险见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §4.1；Windows 版只支持访问本机。

### 2.8 怎样给新手机添加 VPN？忘了 VPN 管理页的密码？

- **Linux**：浏览器打开 `https://<访问地址>:8443`（wg-easy 管理页），点"新建客户端"，用手机扫描二维码。管理员用户名 `hvadmin`，密码在 `secrets/wg_easy_admin_password` 里。忘了密码或丢了 wg-easy 的两步验证：`sudo ./hv vpn reset-password`；
- **Windows**："HomeVault 管理"菜单选 `6 添加手机VPN`，或 `.\windows\hv.ps1 vpn add phone-mama`。名称只能用英文字母、数字和 `_ = + . -`，最多 15 个字符。

每部手机用自己的一份配置，不要多台设备共用。

## 3. 证书（HTTPS）

### 3.1 浏览器或手机提示"证书不受信任""您的连接不是私密连接"？

你用的是 **IP 模式**：证书由 HomeVault 自己的"本地 CA"签发，每台设备要**安装一次根证书**：

```bash
sudo ./hv ca                      # 显示指纹和各系统的安装方法
sudo ./hv ca --export /tmp/HomeVault-CA.crt
```

也可以在管理面板"设置"页下载根证书。安装后**核对 SHA-256 指纹**和 `ca` 命令显示的一致。手机上要安装成"**CA 证书**"（不是"VPN 和应用用户证书"），见 [docs/05-安卓手机备份.md](05-安卓手机备份.md) §3；电脑见 [docs/06-电脑使用.md](06-电脑使用.md) §1.2。

不想在每台设备上装证书？有自己的域名的话可以改用**域名模式**，证书自动申请，所有设备直接信任。

### 3.2 电脑客户端提示"服务器强制执行严格传输安全（HSTS），不接受不受信任的证书"？

HomeVault 发送了 HSTS 安全头，Nextcloud 桌面客户端因此**不允许**"仍然信任此证书"。必须把根证书装进**操作系统的受信任根证书**里（Windows："本地计算机 → 受信任的根证书颁发机构"），然后重启客户端。步骤见 [docs/06-电脑使用.md](06-电脑使用.md) §1.2。

### 3.3 根证书会过期吗？

本地 CA 的根证书有效期大约 10 年（3600 天）；网站证书由 Caddy 自动续期（每 12 小时一张新的），不用你管。备份里包含了本地 CA，整机恢复后根证书不变，设备不用重新安装。

### 3.4 以前好好的，突然所有设备都报证书错误？

- 手机或电脑的**日期时间**错了：打开"自动设置日期和时间"；
- 服务器**重新安装**过，并且没有从备份恢复：新装会生成新的本地 CA，所有设备要安装新的根证书，并删除旧的。从备份整机恢复则会保留原来的 CA（见 [docs/07-备份与恢复.md](07-备份与恢复.md)）；
- 访问地址填错了（例如填成了公网域名或 VPN 地址）：证书只对安装时的访问地址有效。

### 3.5 域名模式：证书一直申请不下来？

查看日志：`sudo ./hv logs caddy`。常见原因：DNS 服务商的 API 密钥填错、被删除或权限不够；域名还没实名认证；主机访问不了外网。修好后运行 `sudo ./hv restart`。还要确认这个域名的 A 记录指向的是**局域网 IP**，并注意部分路由器的"DNS 重绑定保护"会拦截这种解析，见 [docs/04-VPN与DDNS.md](04-VPN与DDNS.md) §6.1。

## 4. 手机备份

### 4.1 照片只在打开 Nextcloud App 时才上传，平时不动？

国产手机系统会杀后台。按 [docs/05-安卓手机备份.md](05-安卓手机备份.md) §6 给 **Nextcloud 和 VPN App 都**设置好：允许自启动、电池"无限制"、锁定最近任务、允许后台活动。这是手机自动备份最常见的问题。

### 4.2 手机上删了照片，服务器上的也会被删吗？

**不会。** Nextcloud App 的"自动上传"是单向的：只把手机上的新照片传上去，手机上删除不会影响服务器。所以照片上传成功后，可以放心在手机上清理空间（先在网页上确认照片确实在服务器上）。

注意自动上传设置里的"**原始文件将会被…**"选项：选"被删除"会在上传后**自动删掉手机上的原图**，一定要选"**保留在原始文件夹**"（见 [docs/05-安卓手机备份.md](05-安卓手机备份.md) §5.3）。

### 4.3 手机备份一次要多久？会不会费流量、费电？

第一次上传全部相册可能要几个小时，建议连着家里 Wi-Fi、插着充电器过夜完成。之后只上传新照片，几乎感觉不到。建议在自动上传里打开"**仅通过无流量限制的 Wi-Fi 上传**"，出门在外就不会消耗流量；VPN 保活保持默认的 0，最省电。

### 4.4 大视频上传失败或反复重传？

大视频最好在家里 Wi-Fi 下传。在外面网络不稳定时，可以在 VPN App 里把 MTU 改成 1280 试试。也请管理员用 `doctor` 检查服务器剩余空间。服务器端对单个文件大小没有限制（App 使用分块上传）。详见 [docs/05-安卓手机备份.md](05-安卓手机备份.md) §12。

### 4.5 两部手机能用同一个账号备份吗？

可以，但**每部手机要备份到自己的文件夹**（例如 `/手机备份/小米15-妈妈/`、`/手机备份/华为P60-妈妈/`），否则同名文件会互相冲突。每部手机登录时都会生成自己的"设备密码"，丢了哪部就撤销哪部。

### 4.6 为什么 Nextcloud App 要从 GitHub 或 F-Droid 下载，应用商店里没有？

国内的应用市场一般没有上架 Nextcloud 官方 App。请从 [docs/05-安卓手机备份.md](05-安卓手机备份.md) §1 列出的官方地址下载，不要用来路不明的"下载站"。F-Droid 版和 GitHub 版签名不同，不能互相覆盖升级，选定一个来源就一直用它。

### 4.7 华为 HarmonyOS NEXT（纯血鸿蒙）能用吗？

HarmonyOS NEXT（HarmonyOS 5 及以后）不能安装安卓 APK，所以 Nextcloud、WireGuard 的安卓 App 都用不了。只能在家连着 Wi-Fi 时用浏览器上传，外出时无法连回家。HarmonyOS 4.x 及更早的版本可以正常使用。详见 [docs/05-安卓手机备份.md](05-安卓手机备份.md) §10。

## 5. 电脑使用

### 5.1 电脑上装了 Nextcloud 客户端，会不会把 2 TB 全部下载到电脑？

不会，只要开启"**虚拟文件**"：文件只显示为占位图标，打开时才下载，也可以只同步你选的文件夹。见 [docs/06-电脑使用.md](06-电脑使用.md) §2.3。

### 5.2 在 Windows 里"映射网络驱动器"，大文件复制失败、显示的剩余空间不对？

Windows 自带的 WebDAV（WebClient 服务）默认单个文件上限约 50 MB，显示的剩余空间也是 C 盘的，而且微软已经不再推荐这个功能。请改用 Nextcloud 桌面客户端或 rclone，见 [docs/06-电脑使用.md](06-电脑使用.md)。

### 5.3 在电脑客户端里删除了文件，服务器上也没了？

是的，桌面客户端的同步是**双向**的。误删后在网页"文件"左下角的"**回收站**"里恢复；超过 30 天或回收站被清空的，从备份恢复（见 [docs/07-备份与恢复.md](07-备份与恢复.md) §8）。

## 6. 存储与多块硬盘

### 6.1 硬盘上已经有很多照片，怎样让它们出现在 Nextcloud 里？

**不要**把它们复制进 Nextcloud 的数据目录。把那个文件夹添加为"**额外存储**"：

```bash
sudo ./hv storage add        # 按提示填名称、路径、只读/读写、是否备份、哪些用户可见
sudo ./hv storage apply
sudo ./hv occ files:scan --all   # 让已有的文件立刻出现
```

它会以一个文件夹的形式出现在网页和 App 里。见 [docs/06-电脑使用.md](06-电脑使用.md) §5、[docs/08-日常运维与升级.md](08-日常运维与升级.md) §6。

### 6.2 能不能直接在资源管理器或文件管理器里往 Nextcloud 数据目录里拷文件？

不建议。Nextcloud 不知道这些文件，网页上看不到，还可能出现权限问题（Linux 上数据目录属于 uid 33）。正确的做法是网页上传、桌面客户端同步，或者用"额外存储"。实在拷了，要运行 `sudo ./hv occ files:scan --all`。Windows 上还要注意 NTFS **不区分大小写**：`Photo.jpg` 和 `photo.jpg` 不能放在同一个文件夹里。

### 6.3 备份盘能和数据盘是同一块硬盘吗？分成两个分区行不行？

不行。同一块物理硬盘坏了，数据和备份会**一起**丢失，分两个分区、两个盘符也一样。安装程序（Linux 的 `storage list` 和管理面板"存储"页也会）发现这种情况会给出严重警告。请准备另一块物理硬盘，USB 移动硬盘也可以。

### 6.4 额外存储里的文件会被备份吗？

只有 `storage.conf` 里"是否备份"为 `yes` 的才会。`sudo ./hv storage list` 可以查看每个存储的设置。能重新下载的影视资料可以选 `no`，照片等不可替代的一定选 `yes`，并确认备份盘装得下。

### 6.5 硬盘快满了怎么办？

`doctor` 和管理面板"概览"页会在某块硬盘可用空间低于 10% 时警告，"存储"页能看到每块硬盘和每个人用了多少。可以：给家人设置配额（网页"用户"页面，或 `user add --quota 500GB`）；清空回收站；加一块硬盘作为额外存储；或者迁移到更大的数据盘。见 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §5.1、§6。

## 7. 备份与恢复

### 7.1 Nextcloud 里已经有一份了，为什么还要 restic 备份？

Nextcloud 里的是"主数据"，不是备份。硬盘坏了、被勒索病毒加密了、同步把删除同步到了服务器，Nextcloud 里的那一份会一起出问题。restic 备份在**另一块硬盘**上，加密保存约一年的历史。原理和 3-2-1 原则见 [docs/07-备份与恢复.md](07-备份与恢复.md) §1。

### 7.2 restic 密码丢了怎么办？

- 服务器还正常：马上查看并抄下来：`sudo cat secrets/restic_password`（Windows：`Get-Content .\secrets\restic_password`）；
- 服务器已经坏了，纸上也没有：**已有的备份永远无法打开**，任何人（包括 restic 作者）都没有办法。这就是为什么安装时要求你离线保存。

### 7.3 误删的文件怎么找回？

按顺序试：① 网页"文件"左下角的"**回收站**"（至少保留 30 天）；② 文件被改坏了，看"详细信息 → **版本**"；③ 都没有了，管理员从 restic 备份里恢复：

```bash
sudo ./hv restore                                        # 列出快照
sudo ./hv restore --files "/src/nextcloud-data/<用户名>/files/<路径>" --snapshot <ID>
```

恢复出来的文件在 `restore/<时间>/` 下。完整步骤见 [docs/07-备份与恢复.md](07-备份与恢复.md) §8.3。

### 7.4 备份要多久、占多大空间？

第一次备份要把全部数据写一遍，1 TB 大约要几个小时；之后每晚只备份变化的部分，通常几分钟。照片视频基本不能压缩，被删除的文件还会在旧快照里保留约一年，所以备份盘最好是数据量的 1.5 倍以上。

### 7.5 备份时 Nextcloud 还能用吗？手机提示"维护模式"是怎么回事？

能用。只有导出数据库的几秒到几分钟里，Nextcloud 处于维护模式，手机 App 这时会提示"维护模式"，自动上传会稍后自动重试，不会丢照片。如果维护模式一直不结束（例如备份时停电了），运行 `sudo ./hv occ maintenance:mode --off`。

### 7.6 `doctor` 或管理面板提示"超过 48 小时没有成功备份"？

看备份日志（管理面板"备份"页 → "查看备份日志"，或 `HV_LOG_DIR/backup/`）。常见原因：

- 移动硬盘没接上或没挂载，日志里是"备份目录不存在"；
- Windows：备份时间点电脑在**睡眠**、HomeVault 账户**没有登录**、或 Docker Desktop 没启动；
- 上次备份被中断留下了锁，日志里是"无法锁定仓库"：确认没有备份正在运行后，运行 `sudo ./hv backup --unlock`（Windows：`.\windows\hv.ps1 backup --unlock`）。

修好后手动运行一次 `sudo ./hv backup`，确认成功。

### 7.7 能同时备份到移动硬盘和云上吗？能备份到百度网盘、阿里云盘吗？

HomeVault 的自动备份一次只写一个目标：本地硬盘，或者 S3 兼容的对象存储（阿里云 OSS、腾讯云 COS 等）。百度网盘、阿里云盘这类个人网盘不是 S3 接口，不支持。想要本地加异地两份，推荐**两块移动硬盘轮换**，一块放在别处，或者本地备份后再用 rclone 复制到云上。见 [docs/07-备份与恢复.md](07-备份与恢复.md) §9。

### 7.8 电脑整个坏了，怎样在新电脑上恢复？

只要有**备份盘**（或云存储密钥）和**抄在纸上的 restic 密码**，就能在新电脑上恢复到坏之前的样子，手机和电脑基本不用重新设置。步骤见 [docs/07-备份与恢复.md](07-备份与恢复.md) §8.5。建议每季度演练一次。

## 8. 日志

### 8.1 日志在哪里？怎么看？

所有 HomeVault 管理的日志都在日志目录 `HV_LOG_DIR` 里：

- Linux 默认 `/srv/homevault/logs`（数据目录下的 `logs`）；
- Windows 默认 `<数据盘>:\HomeVault\logs`，可以直接在资源管理器里打开（菜单 `12 打开日志文件夹`，或 `.\windows\hv.ps1 logs open`）。

| 子目录 | 内容 |
|---|---|
| `homevault/` | 每条管理命令的记录 `hv-年-月-日.log`（不记录密码） |
| `backup/` | 每次备份一个文件 `backup-年月日-时分秒.log` |
| `nextcloud/` | Nextcloud 运行日志 `nextcloud.log` 和审计日志 `audit.log`（登录、文件操作、分享、设置变更） |
| `caddy/` | HTTPS 网关访问日志 `access.log`（谁在什么时候访问了什么） |
| `containers/` | 每天导出的前一天各容器日志 `<服务>-年-月-日.log` |
| `panel/` | 管理面板操作记录 `panel.log` |

查看方式，任选一种：

- **管理面板**的"**日志**"页（手机 App 里也有）：按类型浏览、搜索、下载，还能看容器的实时日志；
- 命令行：

  ```bash
  sudo ./hv logs                               # 实时跟随容器日志（Ctrl+C 退出）
  sudo ./hv logs app                           # 只看某个服务
  sudo ./hv logs list                          # 列出日志文件
  sudo ./hv logs show nextcloud/nextcloud.log --lines 100   # 文件路径相对于日志目录
  sudo ./hv logs show caddy                    # 某个容器最近的输出
  ```

- Nextcloud 网页：**管理设置 → 日志**（运行日志）。
- Windows 菜单 `4 查看日志`。

### 8.2 日志保留几天？怎样修改？

默认保留 **7 天**，每天的维护任务会删除更早的日志文件。安装时可以选择天数（1–365），以后随时修改，任选一种：

- **管理面板**："设置"页或"日志"页里的"**日志保留天数**" → 输入天数 → 保存。服务器会在约 2 分钟内生效；
- **Linux**：

  ```bash
  sudo ./hv logs retention          # 查看当前天数
  sudo ./hv logs retention 30       # 改成 30 天
  sudo ./hv logs clean              # 立即按当前天数清理一次
  ```

- **Windows**："HomeVault 管理"菜单选 `5 日志保留天数`，或 `.\windows\hv.ps1 logs retention 30`。

新的天数在下一次每日维护时生效；HTTPS 访问日志的滚动设置会在 Caddy 容器重建后生效（修改命令会自动处理）。

### 8.3 日志会不会把硬盘写满？

一般不会：所有日志都按保留天数删除；Nextcloud 日志超过 50 MB、HTTPS 访问日志超过 50 MiB 会滚动；Docker 自己的容器日志每个容器最多 3 个 10 MB 的文件。保留天数设得很大（例如 365 天）而访问量又大时，可以在管理面板"存储"页留意一下日志目录所在硬盘的剩余空间。

### 8.4 日志里会不会有密码？

HomeVault 自己生成的密码不会写进日志：Windows 的命令日志只记录命令名；Linux 的命令日志会记录参数，但 `--password`、`--secret`、`--token` 这类参数的值会替换成 `***`。⚠️ `occ` 命令的参数会**原样**记录，所以不要在 `occ` 命令行里直接写密码（例如 `occ config:system:set … --value=密码`），改在网页上设置。HTTPS 访问日志会自动隐去 Cookie 和登录凭据等敏感请求头。但日志里仍有**文件名、用户名和 IP 地址**，请把日志当作隐私资料，不要随意发给别人；求助时发之前先检查一遍。

## 9. 安全

### 9.1 管理面板用什么账号登录？

用 **Nextcloud 账户**登录，而且只有 Nextcloud "**admin**"组（管理员）的成员才能进入。点"使用 Nextcloud 登录"，会打开 Nextcloud 的登录页，在那里完成密码和两步验证，再点"授权访问"（英文界面是 Grant access）即可；也可以用"用户名 + 应用密码"登录。每次登录会在 Nextcloud 里生成一个名为"HomeVault 管理面板（你的 IP）"的设备密码，退出登录时自动删除。登录 12 小时后需要重新登录。

想让另一位家人也能进面板：把他加入 admin 组（网页 **用户** 页面，或 `sudo ./hv occ group:adduser admin <用户名>`）。但管理员能管理所有账户，请只给真正需要的人。

### 9.2 家人之间能看到彼此的照片吗？管理员能看到吗？

每个账户的文件默认只有自己能看到，除非主动分享。网页上的管理员账户也看不到别人的文件。但要知道：**能登录服务器的人**（有 root/管理员权限）在技术上可以直接读取硬盘上的所有文件，Nextcloud 没有对家人隐藏这一点的能力。

### 9.3 为什么强制所有人开启两步验证？

家庭服务器里是全家的照片和通讯录。即使密码被猜到或泄露，没有手机上的验证码也登录不了。第一次登录时按提示绑定身份验证器 App（例如 Microsoft Authenticator），并**保存好备用码**。手机登录 Nextcloud App、DAVx⁵ 用的是每台设备单独的"设备密码/应用密码"，不受影响。

### 9.4 家里有 IPv6，会不会把服务暴露到公网？

不会。HomeVault 的端口**只绑定在局域网 IPv4 地址上**（Linux），不监听 IPv6；Windows 由 Windows 防火墙只放行局域网和 VPN 网段。路由器上也只转发一个 UDP 端口。原理见 [docs/01-架构与安全.md](01-架构与安全.md) §3.2。

### 9.5 可以开"公开分享链接"发给朋友吗？

默认关闭。可以在 `.env` 里设置 `HV_ALLOW_PUBLIC_LINKS=true`，然后 `sudo ./hv up` 开启（开启后强制链接密码）。但要明白：服务器**不在公网上**，朋友在外面**打不开**这个链接，除非他也在你家局域网或 VPN 里。要给外人发文件，更简单的办法是下载下来用聊天软件发送。

### 9.6 为什么不开 Nextcloud 的"服务端加密"？

它的密钥和数据在同一台服务器上，挡不住攻击者，却会让备份恢复变复杂、增加丢数据的风险。HomeVault 推荐用全盘加密（Linux LUKS2 / Windows BitLocker）加上加密的 restic 备份。详见 [docs/01-架构与安全.md](01-架构与安全.md) §5。

### 9.7 手机丢了怎么办？

尽快在网页"个人设置 → 安全 → 设备和活动链接"里撤销这部手机，删除它的 VPN 配置，必要时重置两步验证。完整步骤见 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §10。

## 10. 性能

### 10.1 网页上的相册打开很慢，缩略图一直在转圈？

缩略图是第一次浏览时**现场生成**的，几千张照片第一次打开会慢，看过一遍之后就快了。其他常见原因：数据在 USB 移动硬盘或很慢的机械硬盘上；内存太小（建议 Linux ≥ 4 GB、Windows ≥ 16 GB）；Windows 版的数据目录在 NTFS 上，经过 WSL2 访问本来就比 Linux 慢。照片很多、主要当相册用的话，Linux 版体验更好。

### 10.2 第一次上传几万张照片特别慢？

正常。每个文件都要加密传输、写入、登记到数据库，小文件多时速度主要取决于文件数量。建议：服务器用网线接路由器；手机在家里 Wi-Fi 下、插着充电器过夜上传；多部手机不要同时做第一次全量上传。

### 10.3 Windows：Docker Desktop 占了很多内存和 C 盘空间？

可以在 `%UserProfile%\.wslconfig` 里限制 WSL 的内存，并把 Docker Desktop 的虚拟磁盘移到别的盘。见 [docs/03-Windows部署.md](03-Windows部署.md) §3.3、§3.4。

## 11. 升级

### 11.1 怎样升级？多久升级一次？

每月一次：

```bash
sudo ./hv update
```

它会**先自动备份**，再拉取当前大版本的最新镜像并重建容器。备份失败时会停止升级。详见 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §3。

### 11.2 Nextcloud 能跳过大版本直接升级吗（例如 34 → 36）？

不能。Nextcloud 一次只能升一个大版本，跳级时容器会拒绝启动。用 `sudo ./hv update --major` 升一级，确认正常后再升下一级。大版本升级前请看 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §3.3。

### 11.3 升级后网页打不开，或者一直显示"需要更新"？

先看日志：`sudo ./hv logs app`。显示"需要更新"时运行：

```bash
sudo ./hv occ upgrade
sudo ./hv occ maintenance:mode --off
```

实在不行，可以用升级前自动做的那次备份整机恢复，见 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §3.3 和 [docs/07-备份与恢复.md](07-备份与恢复.md) §8.4。

### 11.4 怎样升级 HomeVault 套件本身？

下载新版本（`git pull` 或下载新的 ZIP 覆盖，保留 `.env`、`secrets/`、`storage.conf`、`state/`），然后重新运行一次 `install`。见 [docs/08-日常运维与升级.md](08-日常运维与升级.md) §3.5。

## 12. 安卓管理 App 与管理面板

### 12.1 管理面板在哪里打开？能做什么？

浏览器打开 `https://<访问地址>:9443`（例如 `https://192.168.1.10:9443`），在家连 Wi-Fi 或在外连上 VPN 时都能打开。页面有：**概览**（各服务状态、警告）、**存储**（每块硬盘的用量、每个人的空间）、**备份**（状态、快照、"立即备份"）、**日志**、**VPN**（各设备最近一次连接时间和流量）、**设置**（日志保留天数、根证书、安卓 App 下载）。它只能**查看**和做少数安全的操作（立即备份、清理日志、改保留天数、重启某个服务），不能删除数据，也不能恢复备份。完整说明见 [docs/10-安卓管理App与管理面板.md](10-安卓管理App与管理面板.md)。

### 12.2 安卓管理 App 在哪里下载？

App 名叫"**HomeVault 家庭归档**"，需要 Android 8.0 及以上。两种方式：

1. **从自己的服务器下载**（推荐）：管理员先在服务器上运行一次

   ```bash
   sudo ./hv android fetch
   ```

   Windows 上是 `.\windows\hv.ps1 android fetch`。它会从项目的 GitHub 发布页下载最新的 APK，保存到 `state/app/homevault.apk`。之后用电脑打开管理面板的"**设置**"页，用手机扫描"安卓应用"的二维码下载，或者在手机浏览器里直接打开 `https://<访问地址>:9443/download/android`（手机要连着家里 Wi-Fi 或 VPN）。服务器访问不了 GitHub 时，可以在别的电脑上下载好 APK，拷到服务器上，再运行 `sudo ./hv android fetch --file <APK 文件路径>`；
2. **直接从 GitHub 下载**：<https://github.com/yuelanxian/-/releases>，下载 `homevault-android.apk`。

它只是管理面板的手机外壳，**和照片备份无关**，家人不需要装。照片备份用的是 Nextcloud 官方 App。

### 12.3 安装 APK 时提示"禁止安装未知来源应用"或"解析软件包时出现问题"？

- "禁止安装未知来源应用"：点"设置"，允许**这个浏览器**（或文件管理器）"安装未知应用"，返回继续安装。部分国产系统的"纯净模式/安全守护"会拦截，确认来源可靠后选择继续安装；
- "解析软件包时出现问题"：手机系统低于 Android 8.0，或者 APK 没下载完整，重新下载一次；
- 华为 HarmonyOS NEXT 不能安装 APK，请直接用手机浏览器打开管理面板地址。

### 12.4 App 提示"证书不受信任"，打不开面板？

IP 模式下，手机要先安装 HomeVault 根证书（和 Nextcloud App 用的是同一个，装过就不用再装）。为了安全，App **不会**忽略证书错误。点 App 里的"证书安装说明"按步骤安装即可，或看 [docs/05-安卓手机备份.md](05-安卓手机备份.md) §3。

### 12.5 App 连接超时，或提示"这看起来是 Nextcloud 的地址"？

- 管理面板的端口是 **9443**，地址应该是 `https://192.168.1.10:9443` 这样，不是 Nextcloud 的地址；
- 在外面要先打开 VPN。App 顶栏的"VPN"按钮可以直接打开 WG Tunnel 或 WireGuard；
- 提示"服务器直接断开了连接"：手机的 IP 不在允许访问的网段里，通常是没有通过家里 Wi-Fi 或 VPN 访问。

### 12.6 登录管理面板时提示没有权限？

只有 Nextcloud "admin" 组的成员能登录，见 [§9.1](#91-管理面板用什么账号登录)。普通家庭成员的账户进不了管理面板，这是故意的。

### 12.7 在面板里点了"立即备份"，一直显示"等待主机执行"？

面板本身不能直接操作服务器，它把请求交给服务器上的一个后台任务执行：

- **Linux**：由 systemd 的 `homevault-requests.path` 触发，正常几秒内就开始（另外每 5 分钟也会检查一次）。检查：`systemctl status homevault-requests.path`。安装时用了 `--no-systemd` 的，这个功能不可用，重新运行一次 `sudo ./hv install`（不加 `--no-systemd`）即可；
- **Windows**：由每 2 分钟运行一次的计划任务 `HomeVault-Requests` 执行。请确认电脑开着、HomeVault 账户已登录、Docker Desktop 在运行，并在"任务计划程序"里检查这个任务是否存在、上次运行结果是否成功。

### 12.8 能在面板或 App 里恢复文件吗？

不能，这是故意的：恢复会覆盖数据，只能由管理员在服务器上执行（见 [docs/07-备份与恢复.md](07-备份与恢复.md) §8）。家人误删了文件，可以自己先去 Nextcloud 网页的"回收站"里找。
